## 三、部署步骤

### 3.1 虚拟机：CentOS 7 基础环境

```bash
# 1. 关闭防火墙和 SELinux
systemctl stop firewalld && systemctl disable firewalld
setenforce 0
sed -i 's/SELINUX=enforcing/SELINUX=disabled/g' /etc/selinux/config

# 2. 更换 YUM 源（CentOS 7 已 EOL，使用阿里云 vault 源）
cd /etc/yum.repos.d/
curl -O https://mirrors.aliyun.com/repo/Centos-7.repo
sed -i 's/mirror.centos.org/vault.centos.org/g' Centos-7.repo
sed -i 's/#baseurl/baseurl/g' Centos-7.repo
sed -i 's/metalink/#metalink/g' Centos-7.repo
yum clean all && yum makecache

# 3. 安装 Docker
yum install -y docker
systemctl enable docker && systemctl start docker
docker --version
```

### 3.6 物理机：部署 Rerank 服务（Python）

```powershell
# 1. 安装 Python 3.11+
# 从 https://www.python.org/downloads/ 下载安装
# 安装时勾选「Add Python to PATH」

# 2. 安装依赖
pip install FlagEmbedding fastapi uvicorn pydantic -i https://pypi.tuna.tsinghua.edu.cn/simple

# 3. 创建 Rerank 服务脚本 (C:\Users\Lenovo\Downloads\rerank_server.py)
@"
from fastapi import FastAPI
from pydantic import BaseModel
from FlagEmbedding import FlagReranker
import uvicorn

app = FastAPI()
reranker = None

class RerankRequest(BaseModel):
    query: str
    documents: list[str]

@app.get('/health')
async def health():
    return {"status": "ok", "model": "bge-reranker-v2-m3"}

@app.post('/rerank')
async def rerank(req: RerankRequest):
    global reranker
    if reranker is None:
        reranker = FlagReranker('BAAI/bge-reranker-v2-m3', use_fp16=False)
    pairs = [[req.query, doc] for doc in req.documents]
    scores = reranker.compute_score(pairs)
    if isinstance(scores, (int, float)):
        scores = [scores]
    result = [{"index": i, "score": float(s)} for i, s in enumerate(scores)]
    return sorted(result, key=lambda x: x["score"], reverse=True)

if __name__ == "__main__":
    uvicorn.run(app, host="0.0.0.0", port=8900)
"@ > C:\Users\Lenovo\Downloads\rerank_server.py

# 4. 启动服务
python C:\Users\Lenovo\Downloads\rerank_server.py

# 5. 开放防火墙
New-NetFirewallRule -DisplayName "Rerank8900" -Direction Inbound -Protocol TCP -LocalPort 8900 -Action Allow

# 6. 设置开机自启（管理员 PowerShell）
$action = New-ScheduledTaskAction -Execute "python" -Argument "C:\Users\Lenovo\Downloads\rerank_server.py"
$trigger = New-ScheduledTaskTrigger -AtStartup
Register-ScheduledTask -TaskName "BgeRerankService" -Action $action -Trigger $trigger -RunLevel Highest -Force
```

## 五、常见问题及解决方案

### 问题 1：容器持续重启

**症状**：`ai-web`、`hz-fe` 容器状态为 `Restarting`

**解决**：
```bash
# 查看日志
docker logs ai-web --tail 100
docker logs hz-fe --tail 100

# 重启所有服务
ai stop && sleep 10 && ai restart
```

### 问题 2：License 文件缺失

**症状**：`Permission denied` 或 `haizhi.license not found`

**解决**：
```bash
# 创建目录并设置权限
sudo mkdir -p /opt/haizhi/license
sudo chown -R haizhi:haizhi /opt/haizhi/license
```

### 问题 3：Ollama 无法外部访问

**症状**：虚拟机能 ping 通物理机，但 `curl http://物理机 IP:11434` 失败

**解决**：
1. 设置环境变量 `OLLAMA_HOST=0.0.0.0:11434`
2. 重启 Ollama 服务
3. 开放防火墙端口 11434

### 问题 4：Docker 镜像拉取失败

**症状**：`connection reset` 或 `unauthorized`

**解决**：
- 使用国内镜像源（阿里云、清华源）
- 或在虚拟机下载后通过 HTTP 传输到物理机

## 七、部署经验总结

### 成功经验

1. **网络配置**：虚拟机必须使用**桥接模式**，确保与物理机同网段互通
2. **Ollama 配置**：必须设置 `OLLAMA_HOST=0.0.0.0:11434` 才能允许外部访问
3. **防火墙**：物理机需开放 11434（Ollama）和 8900（Rerank）端口
4. **端口冲突**：孔明平台默认 8080 端口可能与 adminer 冲突，改为 8081

### 踩坑记录

1. **CentOS 7 YUM 源**：CentOS 7 已 EOL，必须使用 vault 源（阿里云镜像）
2. **Docker 版本**：孔明平台需要 Docker 20.10+， CentOS 7 自带 1.13 需要升级
3. **Alita 服务**：孔明平台强依赖 Alita，但虚拟机无 GPU 无法运行，配置指向物理机
4. **Rerank 模型**：Ollama 不支持 bge-reranker-v2-m3，需用 Python 单独部署
5. **镜像拉取**：物理机网络受限，Rerank 服务用 Python 部署最简单

### 改进建议

1. **GPU 直通**：如条件允许，配置虚拟机 GPU 直通，Alita 服务可在虚拟机运行
2. **服务整合**：可考虑将 Ollama 和 Rerank 都部署在虚拟机，减少网络依赖
3. **监控告警**：建议部署 uptime-kuma（已自带）监控服务健康状态
