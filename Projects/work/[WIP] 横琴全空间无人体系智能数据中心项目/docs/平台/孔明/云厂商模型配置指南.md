# 孔明平台云厂商模型配置指南

> **主题**：孔明平台接入 Kimi、GLM、MiniMax 等云厂商大模型
> **适用范围**：孔明平台 v1.8.1+
> **创建日期**：2026-04-23

---

## 一、配置原理

孔明平台支持通过 **OpenAI 兼容格式** 接入第三方云厂商模型。核心配置原理：

```
孔明平台 → OpenAI 兼容 API → 云厂商模型服务
                ↑
         配置 API Key + Base URL
```

### 支持的云厂商

| 厂商 | 模型系列 | OpenAI 兼容端点 | 状态 |
|------|----------|-----------------|------|
| **Moonshot** | Kimi-K2.6 | ✅ 支持 | 可用 |
| **智谱 AI** | GLM-5.1 | ✅ 支持 | 可用 |
| **MiniMax** | MiniMax-M2.7 | ✅ 支持 | 可用 |

## 二、配置步骤

### 步骤 1：获取云厂商 API Key

#### Moonshot (Kimi)

1. 访问 [Moonshot AI 开放平台](https://platform.moonshot.cn/)
2. 注册/登录账号
3. 进入「API Key 管理」创建新密钥
4. 复制 API Key（格式：`sk-xxxxxxxxxxxxxxxx`）

**可用模型**：
- `moonshot-v1-128k`
- `moonshot-v1-8k`
- `moonshot-v1-32k`

#### 智谱 AI (GLM)

1. 访问 [智谱 AI 开放平台](https://open.bigmodel.cn/)
2. 注册/登录账号
3. 进入「API Key」页面创建新密钥
4. 复制 API Key

**可用模型**：
- `glm-5`
- `glm-4-plus`
- `glm-4-flash`

#### MiniMax

1. 访问 [MiniMax 开放平台](https://platform.minimaxi.com/)
2. 注册/登录账号
3. 创建应用并获取 API Key
4. 复制 API Key 和 Group ID

**可用模型**：
- `minimax-text-01`
- `abab6.5s-chat`

---

### 步骤 2：孔明平台配置

#### 方式一：Web 界面配置（推荐）

1. 登录孔明平台 Web 界面
   ```
   http://192.168.2.100:8081
   ```

2. 进入「系统配置」→「模型配置」

3. 点击「添加模型提供商」

4. 填写配置信息（以 Moonshot 为例）：

   | 配置项 | 值 |
   |--------|-----|
   | 提供商名称 | Moonshot |
   | 模型类型 | LLM |
   | 基础 URL | `https://api.moonshot.cn/v1` |
   | API Key | `sk-xxxxxxxxxxxxxxxx` |
   | 默认模型 | `moonshot-v1-128k` |

5. 点击「测试连接」验证配置

6. 保存配置

#### 方式二：配置文件修改

如需直接修改配置文件，编辑 `~/ai/.env`：

```bash
# 编辑配置文件
vi ~/ai/.env
```

添加/修改以下内容：

```bash
# ========== 云厂商模型配置 ==========

# Moonshot (Kimi)
MOONSHOT_API_KEY=sk-xxxxxxxxxxxxxxxx
MOONSHOT_BASE_URL=https://api.moonshot.cn/v1
MOONSHOT_MODEL=moonshot-v1-128k

# 智谱 AI (GLM)
ZHIPU_API_KEY=xxxxxxxxxxxxxxxx
ZHIPU_BASE_URL=https://open.bigmodel.cn/api/paas/v4
ZHIPU_MODEL=glm-5

# MiniMax
MINIMAX_API_KEY=xxxxxxxxxxxxxxxx
MINIMAX_GROUP_ID=xxxxxxxx
MINIMAX_BASE_URL=https://api.minimaxi.com/v1
MINIMAX_MODEL=minimax-text-01

# 默认使用的模型提供商
DEFAULT_LLM_PROVIDER=moonshot
```

保存后重启服务：

```bash
ai restart
```

## 三、多模型配置示例

### 场景：同时配置多个云厂商

| 应用场景 | 推荐模型 | 提供商 |
|----------|----------|--------|
| 长文本处理 | moonshot-v1-128k | Moonshot |
| 复杂推理 | glm-5 | 智谱 AI |
| 多语言对话 | minimax-text-01 | MiniMax |

### 配置示例

```bash
# ========== 多模型配置 ==========

# 1. Moonshot - 长文本场景
MOONSHOT_API_KEY=sk-abc123
MOONSHOT_BASE_URL=https://api.moonshot.cn/v1
MOONSHOT_MODEL=moonshot-v1-128k

# 2. 智谱 GLM - 推理场景
ZHIPU_API_KEY=glm.def456
ZHIPU_BASE_URL=https://open.bigmodel.cn/api/paas/v4
ZHIPU_MODEL=glm-5

# 3. MiniMax - 对话场景
MINIMAX_API_KEY=minimax.ghi789
MINIMAX_GROUP_ID=group123
MINIMAX_BASE_URL=https://api.minimaxi.com/v1
MINIMAX_MODEL=minimax-text-01

# 默认模型（可根据业务切换）
DEFAULT_LLM_PROVIDER=moonshot
```

### 模型切换方式

1. **应用级别**：不同应用配置不同的 `DEFAULT_LLM_PROVIDER`

2. **对话级别**：在孔明平台对话界面选择模型

3. **API 调用级别**：请求时指定 `model` 参数
   ```json
   {
     "model": "moonshot-v1-128k",
     "messages": [{"role": "user", "content": "你好"}]
   }
   ```

## 四、故障排查

### 问题 1：连接超时

**症状**：模型测试时提示「连接超时」或「Connection timeout」

**排查步骤**：

```bash
# 1. 检查网络连通性
ping api.moonshot.cn

# 2. 检查端口连通性
curl -v https://api.moonshot.cn/v1/models

# 3. 检查 DNS 解析
nslookup api.moonshot.cn

# 4. 检查虚拟机网络（如使用虚拟机部署）
ip route
cat /etc/resolv.conf
```

**解决方案**：
- 检查防火墙规则，放行出站 HTTPS (443)
- 检查 DNS 配置，更换为公共 DNS（如 8.8.8.8, 114.114.114.114）
- 如使用代理，配置代理环境变量

---

### 问题 2：认证失败

**症状**：提示「Unauthorized」、「Invalid API Key」或「认证失败」

**排查步骤**：

1. 检查 API Key 是否正确复制（注意是否有空格）
2. 检查 API Key 是否已过期或被删除
3. 检查 Base URL 是否正确

**解决方案**：

```bash
# 使用 curl 直接测试 API Key
curl https://api.moonshot.cn/v1/models \
  -H "Authorization: Bearer sk-your-api-key" \
  -H "Content-Type: application/json"
```

---

### 问题 3：模型不可用

**症状**：提示「Model not found」或「模型不可用」

**排查步骤**：

1. 检查模型名称是否拼写正确
2. 检查账户是否有该模型的使用权限
3. 检查模型是否在该区域可用

**解决方案**：

```bash
# 查看可用模型列表
curl https://api.moonshot.cn/v1/models \
  -H "Authorization: Bearer sk-your-api-key" | jq
```

## 五、最佳实践

### 1. API Key 管理

```bash
# 建议：使用环境变量或密钥管理服务
# 不要在代码中硬编码 API Key

# 1. 创建环境变量文件（限制权限）
touch ~/ai/.env
chmod 600 ~/ai/.env

# 2. 在配置文件中引用环境变量
echo 'MOONSHOT_API_KEY=${MOONSHOT_API_KEY}' >> ~/ai/.env
```

### 2. 多环境配置

```bash
# 开发环境
~/ai/.env.development

# 测试环境
~/ai/.env.test

# 生产环境
~/ai/.env.production
```

### 3. 成本优化

| 策略 | 说明 |
|------|------|
| 模型分层 | 简单任务用轻量模型，复杂任务用高级模型 |
| 缓存机制 | 重复查询优先使用缓存结果 |
| 批量处理 | 合并多个请求，减少 API 调用次数 |
| 监控告警 | 设置用量阈值，及时预警 |
