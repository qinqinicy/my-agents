  • 技术支持人员

录像路径修复

问题：StreamUI 访问录像返回 /opt/media/bin/www/record directory not found

原因：StreamUI 代码中写死了 /opt/media/bin/www 路径，而实际录像存储在 /opt/media/www

解决方案：

ln -sf /opt/media/www /opt/media/bin/www
ls -la /opt/media/bin/www  # 应显示 -> /opt/media/www

5. 接入配置

5.1 拉流配置（addStreamProxy API）

功能：通过 ZLM API 动态添加拉流任务，将外部视频流拉取到本地并录制。

前置条件：

  • ZLM 服务运行中
  • 流媒体代理地址可达
  • 已知 API 密钥（mysecret123）

操作步骤：

  1. 构造 addStreamProxy 请求
  2. 发送 POST 请求到 ZLM API
  3. 验证流是否成功创建

验证方法：

  • API 返回 {"code":0,"msg":"success"}
  • 流列表中出现新流：curl -s "http://127.0.0.1:80/index/api/getMediaList?secret=mysecret123"

API 端点

POST http://10.129.80.242:80/index/api/addStreamProxy
Content-Type: application/json

请求参数

参数类型必填说明
secretstring是API 密钥（mysecret123）
vhoststring是虚拟主机（填 __defaultVhost__）
appstring是应用名称（如 live）
streamstring是流名称（如 main）
urlstring是源流地址（rtmp/rtsp/hls）
enable_hlsbool否启用 HLS 录制（默认 true）
enable_mp4bool否启用 MP4 录制（默认 false）
hls_demandbool否HLS 按需模式（0=连续录制）

请求示例

场景：cszl（城市治理）

curl -X POST "http://10.129.80.242:80/index/api/addStreamProxy" \
  -H "Content-Type: application/json" \
  -d '{
    "secret": "mysecret123",
    "vhost": "__defaultVhost__",
    "app": "cszl",
    "stream": "machinenest",
    "url": "http://10.129.80.244:21021/apron/UA004768282.flv?eip=10.128.131.250&token=1775546994-NULL-5CA507286EEB7CE9DE157E0F7F136E2F-FLY&vhost=saveVhost",
    "enable_hls": true,
    "enable_mp4": true
  }'

流命名规范：

流 ID内容源地址
machinenest机巢http://10.129.80.244:21021/apron/UA004768282.flv?...（带 token）
drone无人机http://10.129.23.244:21021/uav/D0101206.flv?...（带 token）
5gacamera5G-A基站摄像头rtmp://10.129.80.244/proxy_example

常见错误

错误信息原因解决方案
Required parameter missed: vhost缺少 vhost 参数添加 "vhost":"__defaultVhost__"
connection refused源流地址不可达检查源流服务器和网络连通性
wait http response header timeout网络隔离或防火墙Docker 使用 --network host

5.3 录像同步配置

功能：配置 rclone 将本地录像同步到 MinIO 存储

前置条件：

  • rclone 已安装并配置
  • MinIO 服务正常

操作步骤：

  1. 创建同步脚本
  2. 配置定时任务
  3. 验证同步结果

验证方法：

  • /root/mc ls minio/csZl-media/cszl/ 显示同步的文件
  • 同步日志无错误

sync_by_scene.sh 脚本

#!/bin/bash
set -e

LOG="/opt/media/logs/sync.log"
SRC_DIR="/opt/media/www/record"

log() {
    echo "[$(date '+%Y-%m-%d %H:%M:%S')] $1" | tee -a "$LOG"
}

RCLONE="/opt/media/tools/rclone"

for scene_dir in "$SRC_DIR"/*/; do
    [[ -d "$scene_dir" ]] || continue
    scene=$(basename "$scene_dir")

    # 跳过非场景目录
    if [[ "$scene" == "live" ]] || [[ "$scene" == "proxy_example" ]]; then
        continue
    fi

    # 检查桶是否存在
    if ! $RCLONE ls "minio:${scene}-media/" --max-depth 0 &>/dev/null; then
        log "WARNING: Bucket ${scene}-media not found, skipping sync"
        continue
    fi

    log "=== Syncing scene: $scene ==="
    $RCLONE sync "$scene_dir" "minio:${scene}-media/" \
        --exclude "**/.*" \
        --transfers 4 \
        --checkers 8 \
        --log-level INFO \
        -P \
        2>&1 | tee -a "$LOG"

    log "=== Done: $scene ==="
done

同步逻辑：

  • 遍历 /opt/media/www/record/ 下所有场景目录
  • 跳过 live、proxy_example 等非场景目录
  • 检查 MinIO 桶是否存在，不存在则跳过（不报错）
  • 同步到对应桶：minio:{场景}-media/{场景}/

路径映射：

本地路径MinIO 路径
/opt/media/www/record/cszl/machinenest/cszl-media/cszl/machinenest/
/opt/media/www/record/cszl/drone/cszl-media/cszl/drone/
/opt/media/www/record/cszl/5gacamera/cszl-media/cszl/5gacamera/

定时任务配置

# 添加到 crontab，每 5 分钟执行一次
crontab -e

# 内容：
*/5 * * * * /opt/media/tools/sync_by_scene.sh >> /opt/media/logs/sync.log 2>&1

手动执行

# 手动执行同步（实时显示进度）
/opt/media/tools/rclone sync /opt/media/www/record/ minio:cszl-media/cszl/ --exclude "**/.*" -P

8. 故障排除

8.1 常见问题汇总

Q1: StreamUI 看不到视频流

问题现象：StreamUI 界面显示流离线

可能原因：

  • ZLM Docker 网络模式错误
  • 拉流 API 参数遗漏

处理步骤：

  1. 检查 ZLM 是否使用 host 网络：docker ps | grep zlm
  2. 检查网络模式是否为 --network host
  3. 重新创建容器：
docker stop zlm && docker rm zlm
docker run -d --name zlm --network host \
  -v /opt/media/conf:/opt/media/conf \
  -v /opt/media/www:/opt/media/www \
  zlmediakit/zlmediakit:master

Q2: 拉流失败 - connection refused

问题现象：API 返回 {"code":-1,"msg":"connection refused"}

可能原因：

  • 源流地址不可达
  • 代理 URL 未注册

处理步骤：

  1. 确认源地址可访问：curl -s --connect-timeout 5 rtmp://source:1935/live/stream
  2. 联系平台方获取正确的代理 URL

Q3: 录像不同步到 MinIO

问题现象：MinIO 中没有新录像文件

可能原因：

  • rclone 服务未运行
  • 同步脚本执行失败
  • 正在录制的文件（以 . 开头）被排除

处理步骤：

  1. 检查 rclone 服务：systemctl status rclone-minio
  2. 检查同步日志：tail /opt/media/logs/sync.log
  3. 手动执行同步测试：/opt/media/tools/sync_by_scene.sh

Q4: 第三方无法访问视频

问题现象：访问 http://IP:8091 返回连接失败

可能原因：

  • rclone 未绑定 IPv4
  • 防火墙未开放端口

处理步骤：

  1. 检查监听地址：ss -tlnp | grep 8091
  2. 如显示 [::]:8091，需要添加 --bind 0.0.0.0
  3. 修改 systemd 服务并重启：
ExecStart=/opt/media/tools/rclone serve http minio:cszl-media/cszl/ --addr 0.0.0.0:8091 --user cszlkey --pass 'Ka93@fnnbd2A' --vfs-cache-mode writes --bind 0.0.0.0
systemctl daemon-reload
systemctl restart rclone-minio

Q5: rclone sync 传输正在录制的文件失败

问题现象：报错 corrupted on transfer: sizes differ

可能原因：

  • 文件正在被 ZLM 写入，大小不断变化

处理步骤：

  1. 排除以 . 开头的临时文件：
/opt/media/tools/rclone sync /opt/media/www/record/ minio:cszl-media/cszl/ --exclude "**/.*" -P
  1. 等录制完成后再同步
