6. 数据查询

操作SQL
查询所有数据SELECT * FROM root.cszl.uav
查询指定设备SELECT * FROM root.cszl.uav.D0101209
条件查询SELECT * FROM root.cszl.uav WHERE time > 1776747236000
限制行数SELECT * FROM root.cszl.uav LIMIT 10
时间范围SELECT * FROM root.cszl.uav WHERE time >= 1776747236000 AND time <= 1776747240000
聚合统计SELECT COUNT(*) FROM root.cszl.uav
平均值SELECT AVG(lat) FROM root.cszl.uav
最大值SELECT MAX(alt) FROM root.cszl.uav WHERE time > 1776747236000
最新数据SELECT LAST * FROM root.cszl.uav

7. REST API

端口 18080，Basic Auth (root:root)，路径 /rest/v2/nonQuery（写入） /rest/v2/query（查询）

健康检查

curl -s "http://10.129.80.142:18080/ping"

创建存储组

curl -X POST "http://10.129.80.142:18080/rest/v2/nonQuery" -H "Content-Type: application/json" -u "root:root" -d '{"sql": "CREATE DATABASE root.yyzx"}'

查询数据

curl -X POST "http://10.129.80.142:18080/rest/v2/query" -H "Content-Type: application/json" -u "root:root" -d '{"sql": "SHOW DATABASES"}'

写入数据

curl -X POST "http://10.129.80.142:18080/rest/v2/nonQuery" -H "Content-Type: application/json" -u "root:root" -d '{"sql": "INSERT INTO root.cszl.uav (time, flyId, lat, lon) VALUES (1776747236000, '\''D0101209'\'', 22.1, 113.5)"}'

8. MQTT 服务

8.1 配置项（iotdb-system.properties）

配置项值说明
enable_mqtt_servicetrue启用 MQTT 服务
mqtt_host0.0.0.0监听地址
mqtt_port1883MQTT 端口
mqtt_handler_pool_size16处理器线程数
mqtt_payload_formatterjsonJSON 格式解析
mqtt_max_message_size1048576最大消息 1MB

8.2 重启生效

$IOTDB_HOME/sbin/stop-datanode.sh && $IOTDB_HOME/sbin/start-datanode.sh

9. 设备模板

操作SQL
创建模板CREATE DEVICE TEMPLATE template_name (measurement1 DATATYPE, measurement2 DATATYPE)
激活模板SET DEVICE TEMPLATE template_name TO root.db.device
查看模板SHOW DEVICE TEMPLATES / SHOW TEMPLATES
解绑模板DEACTIVATE DEVICE TEMPLATE template_name FROM root.db.device
删除模板DROP DEVICE TEMPLATE template_name
注意：模板必须先解绑才能删除。
