## WireGuard 故障排查（2026-05-09）

### 故障现象
Mac 连接 WireGuard VPN 后，ping 10.0.0.1 完全不通（100% packet loss）

### 已完成的排查
1. ✅ WireGuard 服务端正常运行（`wg show` 显示 peer 10.0.0.4）
2. ✅ UDP 1194 端口监听正常（`ss -ulnp` 确认）
3. ✅ YJ-FIREWALL-INPUT 已放行 UDP 1194
4. ✅ IP forwarding 已开启（`cat /proc/sys/net/ipv4/ip_forward` = 1）
5. ✅ MASQUERADE 规则已添加

### 可能原因
- PostUp 脚本中 `eth0` 网卡名在腾讯云上可能不正确（腾讯云内网网卡名可能是 `eth0`，但外网出口不同）
- 腾讯云内网地址是 10.1.20.2（eth0），但公网通过 SNAT 出入口不是 eth0
- 需检查实际网卡名和路由表

### 下一步
- 检查腾讯云实际网卡名（`ip a` 或 `ip addr`）
- 确认 wg0 的 PostUp MASQUERADE 是否正确生效
- 检查 `iptables -t nat -L POSTROUTING -n -v` 确认 MASQUERADE 规则
