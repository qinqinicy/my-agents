# 2026-04-24 日志

## 视频平台 ZLM → SRS 迁移

### 问题：ZLM FFmpegSource 无法 fork 进程
- ZLM addFFmpegSource 返回成功但 FFmpeg 进程从未启动，日志静默
- 原因：Docker + seccomp=2 环境下 ZLM 内部 FFmpegSource spawn 机制失效
- 测试：手动 exec 进入容器跑 ffmpeg 完全正常，说明不是容器网络/资源问题

### 解决方案：迁移至 SRS 5.0
- 拉取离线包 `srs-5.tar`，加载镜像 `ossrs/srs:5`
- 配置 `/opt/media/srs/conf/docker.conf`：
  - RTMP 1935，HTTP API 1985，HTTP Server 18080
  - ingest 功能拉取 `rtmp://10.129.80.244:1935/proxy_example`
  - HLS 录制
- **成功** — SRS ingest 正常工作，容器内自动 fork ffmpeg 拉流
