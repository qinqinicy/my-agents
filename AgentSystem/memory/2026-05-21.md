**新增场景 dkqx（低空气象）**：
- 桶名：dkqx-data
- 用户：dkqxkey
- Secret Key：Xk7#Qm9$vL3Np5@Zr8
- 用途：存储低空气象实况网格数据（NetCDF .nc 文件）
- 写入方式：S3 API（数据源方直写 MinIO）
- 读取方式：S3 API / rclone :8093

**MinIO 服务器（10.129.80.211）操作**：
- 桶已创建：`mc mb minio/dkqx-data`
- 用户已创建：`mc admin user add minio dkqxkey 'Xk7#Qm9$vL3Np5@Zr8'`
- 策略已附加：`mc admin policy attach minio readwrite --user dkqxkey`
- 需额外执行 S3 写入策略（见下方命令）

**S3 写入权限配置命令**（MinIO 10.129.80.211 上执行）：
```bash
cat > /tmp/dkqx-write-policy.json << 'EOF'
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": ["s3:PutObject", "s3:GetObject", "s3:ListBucket"],
      "Resource": ["arn:aws:s3:::dkqx-data", "arn:aws:s3:::dkqx-data/*"]
    }
  ]
}
EOF
mc admin policy create minio dkqx-write /tmp/dkqx-write-policy.json
mc admin policy attach minio dkqx-write --user dkqxkey
```
