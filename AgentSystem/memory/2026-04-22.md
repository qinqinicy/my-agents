### ZLMediaKit + StreamUI 视频平台调试

完成视频平台关键问题修复和配置：

**核心问题修复**：
- Docker 网络模式：从 bridge 改为 `--network host`，解决"wait http response header timeout"
- API 参数修正：添加 `vhost=__defaultVhost__` 参数解决"Required parameter missed: vhost"
- HLS 录制路径：`hls_demand=0`（连续录制）+ `hls_save_path=/opt/media/www`
- 录像目录打通：创建 symlink `/opt/media/bin/www` → `/opt/media/www`，解决 StreamUI 录像路径 404

**关键配置**：
- ZLM Docker：`docker run --network host -v /opt/media/conf:/opt/media/conf -v /opt/media/www:/opt/media/www zlmediakit/zlmediakit:master`
- ZLM API 添加拉流：`/index/api/addStreamProxy`，启用 `enable_hls=1` 和 `enable_mp4=1`
- nginx 录像路径：`location /record/ { alias /opt/media/www/record/; autoindex on; }`

**验证通过**：
- VLC 直接拉流：正常播放
- StreamUI 播放：正常
- 录像录制：HLS + MP4 双模式正常
