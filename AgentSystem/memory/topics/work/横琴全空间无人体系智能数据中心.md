### 孔明平台部署技术要点（2026-05-15）

**新服务器**：10.129.80.235，CentOS 7，4T 数据盘挂载 /data，Docker 24.0.7 离线安装，孔明版本 ai_2.0.2

**关键踩坑**：
- Docker 离线安装：解包后 cp docker/* /usr/bin/，docker.sock 需 chmod 666
- License 两路径：alopex_proxy 读 `/opt/haizhi/.license/haizhi.license`，ai-web 读 `/opt/haizhi/license/haizhi.license`，两个目录都要有
- Grafana 插件清理：`rm -rf /opt/haizhi/ai/config/grafana/plugins/*`

**DMC 对接调试（2026-05-18）**：
- Redis 端口：DMC 服务器（192.168.100.161）防火墙默认不开 6679，需 `firewall-cmd --add-port=6679/tcp`
- alchemy 配置：默认无 `application-prod.yaml`，需新建，写入 `client.usercenter.url: http://192.168.100.160:8101`
- brain/config.js：`dmcDomain` 为空时不显示"控制台"按钮，需设 `dmcDomain: "http://192.168.100.160"`
- DMC SSO 跳转：`valid_ec_params` 返回 200 但不自动跳转是 DMC 前端 JS 问题，workaround：复制链接新开页签
- 模型服务已就绪：Alita Proxy(23621)、Embedding(23630)、Rerank(23631)

### IoTDB 技术要点（2026-04-21）
- IoTDB 2.0.7 MQTT 消息格式必须是：`{"device":"root.xxx","timestamp":ms,"measurements":[...],"values":[...]}`
- 普通 flat JSON 不兼容，必须用中间桥接转换或调整数据格式
- REST API 路径：`/rest/v2/nonQuery`（写入）`/rest/v2/query`（查询）
- MQTT port 1883，REST port 18080，RPC port 6667
