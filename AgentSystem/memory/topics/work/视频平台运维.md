## rclone sync 脚本

**位置**: `/opt/media/tools/sync_by_scene.sh`

```bash
#!/bin/bash
set -e
LOG="/opt/media/logs/sync.log"
SRC_DIR="/opt/media/www/record"

RCLONE="/opt/media/tools/rclone"

for scene_dir in "$SRC_DIR"/*/; do
    scene=$(basename "$scene_dir")
    # 跳过非场景目录
    [[ "$scene" == "live" ]] || [[ "$scene" == "proxy_example" ]] && continue
    # 桶不存在则跳过
    $RCLONE lsd minio: | grep -q "${scene}-media" || continue
    $RCLONE sync "$scene_dir" "minio:${scene}-media/" \
        --exclude "**/.*" --transfers 4 --checkers 8 --log-level INFO -P
done
```

**Crontab**: `*/5 * * * * /opt/media/tools/sync_by_scene.sh >> /opt/media/logs/sync.log 2>&1`

## 经验教训

- ZLM Docker 必须使用 `--network host` 否则跨网络通信失败
- addStreamProxy 必须传 `vhost=__defaultVhost__`
- ZLM addStreamProxy 对某些 RTMP URL 格式无法拉取（报错 "rtmp url非法" 或 "end of file"），此时用 ffmpeg 中转
- rclone serve 默认绑定 IPv6，需加 `--bind 0.0.0.0` 绑定 IPv4
- rclone sync 正在录制的文件会报 "sizes differ"，需排除 `.` 开头的临时文件 `--exclude "**/.*"`
- MinIO IAM 可实现按场景桶级别的细粒度权限控制

## WireGuard VPN（2026-05-08/09）

### 腾讯云服务器 WireGuard 部署
- 私钥：`2K4q+GOLkYZgAPVqxqxmg4e74Pi+cF3Fb933XEkDVn8=`
- 公钥：`+ZbN9CSiLmEyahRPDo46SXEIx5LXaRNGJqhrlEPol1Q=`
- 监听：1194/UDP，VPN 网段：10.0.0.0/24

### 腾讯云防火墙（YJ-FIREWALL-INPUT）
- 默认 policy DROP，大量 IP 黑名单
- 放行 WireGuard：`iptables -I YJ-FIREWALL-INPUT 1 -p udp --dport 1194 -j ACCEPT`
- 需添加 MASQUERADE：`iptables -t nat -A POSTROUTING -s 10.0.0.0/24 -o eth0 -j MASQUERADE`

### 故障排查（已解决 2026-05-10）

| 问题 | 原因 | 解决 |
|------|------|------|
| Mac ping 不通 10.0.0.1 | peer 未持久化到 wg0.conf，重启后丢失 | 写入 wg0.conf + `wg-quick down/up` |
| Mac 握手成功但 ping 不通 | YJ-FIREWALL-INPUT 只放行了 UDP 1194，MASQUERADE 未生效 | PostUp 脚本 + 手动添加 NAT 规则 |
| Win1 握手到达服务器但不回复 | PrivateKey 错填为公钥，派生出错误密钥对 | 重新生成正确密钥对，服务器更新公钥 |

### 经验教训

- **WireGuard 配置生成**：`wg genkey` 产私钥，`wg pubkey < priv` 产公钥，严禁混用
- **`wg set` 不持久化**：重启 `wg-quick` 后会丢失，必须写入 wg0.conf
- **握手静默丢弃**：公钥不匹配时 WireGuard 不报错，只是不理，需抓包 + `wg show` 联合排查
- **expect 避坑**：`[]` 被 Tcl 解释，传 WireGuard 配置用 SCP 文件上传
- **腾讯云防火墙**：YJ-FIREWALL-INPUT 链优先级高，INPUT 默认 DROP
