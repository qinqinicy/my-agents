## 核心问题修复记录

### 2026-04-22

**问题 1: StreamUI 看不到视频流**
- 原因: ZLM Docker 网络模式为 bridge，导致跨容器通信失败
- 解决: 改用 `--network host` 模式启动容器

**问题 2: addStreamProxy API 返回 "Required parameter missed: vhost"**
- 原因: 缺少 `vhost=__defaultVhost__` 参数
- 解决: 添加该参数后成功

**问题 3: HLS 录像不生成 .ts 文件**
- 原因: `hls_demand=1`（按需模式）改为 `hls_demand=0`（连续录制）
- 解决: 配置 `hls_demand=0` 和 `hls_save_path=/opt/media/www`

**问题 4: StreamUI 访问录像返回 "/opt/media/bin/www/record directory not found"**
- 原因: StreamUI 代码写死了 `/opt/media/bin/www` 路径
- 解决: `ln -sf /opt/media/www /opt/media/bin/www`

## 关键配置

### ZLM Docker 启动命令
```bash
docker run -d --name zlm --network host \
  -v /opt/media/conf:/opt/media/conf \
  -v /opt/media/www:/opt/media/www \
  zlmediakit/zlmediakit:master
```

### addStreamProxy API 调用
```bash
curl -X POST "http://10.129.80.242:80/index/api/addStreamProxy" \
  -H "Content-Type: application/json" \
  -d '{
    "secret": "mysecret123",
    "vhost": "__defaultVhost__",
    "app": "live",
    "stream": "cszl",
    "url": "rtmp://10.129.80.244:21021/live/cszl",
    "enable_hls": true,
    "enable_mp4": true
  }'
```

### rclone systemd 服务
```ini
[Unit]
Description=rclone MinIO Serve for cszl
After=network.target minio.service

[Service]
ExecStart=/opt/media/tools/rclone serve http minio:cszl-media/cszl/ --addr 0.0.0.0:8091 --user cszlkey --pass 'Ka93@fnnbd2A' --vfs-cache-mode writes --bind 0.0.0.0
Restart=on-failure
RestartSec=10s

[Install]
WantedBy=multi-user.target
```

## 经验教训

- ZLM Docker 必须使用 `--network host` 否则跨网络通信失败
- addStreamProxy 必须传 `vhost=__defaultVhost__`
- rclone serve 默认绑定 IPv6，需加 `--bind 0.0.0.0` 绑定 IPv4
- rclone sync 正在录制的文件会报 "sizes differ"，需排除 `.` 开头的临时文件 `--exclude "**/.*"`
