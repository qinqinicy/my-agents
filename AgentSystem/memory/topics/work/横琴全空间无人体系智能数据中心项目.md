## 项目概述

横琴粤澳深度合作区全空间无人体系智能数据中心项目，主要建设内容包括：

1. **数据资源体系** - 构建 DWD 明细层、DIM 维度层、ADS 应用层的数据分层架构
2. **数据服务审核** - 资源发布、编目、调度、订阅全流程审核能力
3. **专题库建设** - 7 大 ADS 层专题库支撑业务场景运营
4. **本地大模型部署** - Ollama+Qwen3-8B 部署，待集成孔明平台

## 详细设计进展

### 已完成的设计文档

#### 01-ADS 层专题库设计（7 个专题库）

| 专题库 | 核心功能 | 性能要求 |
|--------|----------|----------|
| 场景运营专题库 | 设备监控、轨迹回放、事件识别 | 查询≤5 秒/1 亿条 |
| 营商环境专题库 | 商业热力、需求预测、供需匹配 | 查询≤5 秒/1 亿条 |
| 政策法规专题库 | 法规检索、合规审查、政策评估 | 查询≤5 秒/1 亿条 |
| 交通运输专题库 | 航路分析、空域预警、路径规划 | 查询≤5 秒/1 亿条 |
| 环境支撑专题库 | 适飞指数、气象风险、电磁评估 | 查询≤5 秒/1 亿条 |
| 装备设备专题库 | 健康度评估、故障预测、维保优化 | 查询≤5 秒/1 亿条 |
| 空间资源专题库 | 空间冲突、三维路径、仿真推演 | 查询≤5 秒/1 亿条 |

**设计约束**：
- 数据必须源自 DWD 层和 DIM 层，禁止直接使用原始业务数据
- 关键输出需通过安全审批流程或自动化合规校验
- 涉密数据需加密存储和访问控制

#### 02-数据服务审核设计（6 个审核功能）

| 审核类型 | 核心能力 | 性能要求 |
|----------|----------|----------|
| 资源发布审核 | 数据质量检查、安全合规验证、业务规范评估 | 质量检查≤30 秒/100 万条 |
| 资源编目审核 | 元数据完整性、分类准确性、关联性验证 | 安全验证≤20 秒 |
| 资源调度审核 | 调度策略合理性、资源冲突检测、优先级评估 | 查询≤1 秒 |
| 服务订阅审核 | 订阅资格验证、权限合规性、用量评估 | 并发≥10 个/秒 |
| 异常推送 | 异常识别、分级告警、多渠道通知 | - |
| 异常报告 | 报告生成、趋势分析、根因定位 | - |

**发布审核核心设计**：
- 审核任务创建需验证用户权限（数据服务审核功能权限）
- 同一资源同一时间只能有一个进行中的审核任务
- 驳回需填写不少于 10 字符的原因
- 数据完整性阈值设置范围 90%-100%，默认 99%

## 视频平台集成

### ZLMediaKit + StreamUI 部署

**Docker 网络模式**：必须使用 `--network host`，bridge 模式会导致流媒体超时

**关键配置**：
```ini
[hls]
hls_demand=0        # 0=连续录制，1=按需生成
hls_save_path=/opt/media/www
[record]
appName=record
```

**添加拉流 API**：
```
POST /index/api/addStreamProxy
参数：vhost=__defaultVhost__&app=rtp&stream=test&url=rtsp://...&enable_hls=1&enable_mp4=1
```

**StreamUI 录像路径打通**：
```bash
docker exec streamui mkdir -p /opt/media/bin
docker exec streamui ln -sf /opt/media/www /opt/media/bin/www
```

**nginx 录像访问**：
```nginx
location /record/ {
    alias /opt/media/www/record/;
    autoindex on;
}
```

**运维手册**：`myagents_files/视频平台运维手册.html`

**凭证**：
- StreamUI：`streamui / streamui`
- ZLM：`admin / mysecret123`

**待集成**：MinIO 录像归档（rclone 同步）
