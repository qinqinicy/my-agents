## 工作记录

### 2026-03-17
**问题**: 部署后 API 返回 401 "用户授权过期"

**根因分析**:
1. JAR 包格式错误：Spring Boot 需要 nested JARs 使用 STORED（无压缩）模式
2. Token 字段名不匹配：iPaas OAuth 返回的 JWT 使用标准字段 `sub`/`name`，但代码只检查 `userId`/`userName`
3. 前端 token 获取时序：getUserInfo 在 token 获取前调用

**修复内容**:
- 修改 `JwtToken.java`: 添加多字段名映射（userId/sub/userid, userName/name/username）
- 添加调试日志：打印所有 claims 便于排查
- 修复 JAR 打包：使用 `zip -0` 处理 lib/*.jar，避免压缩
- 环境配置：切换到 pro 环境，更新数据库和 API 地址

**待验证**:
- 部署新版 JAR 到服务器
- 确认 token 字段映射正确

## 技术要点

### JWT Token 结构
**iPaas OAuth Token**（前端传来）:
```json
{
  "sub": "用户ID",
  "name": "用户名",
  "exp": 过期时间戳
}
```

**系统内部 Token**（GetToken.createJwt 生成）:
```json
{
  "userId": "dc63044a4647ec9b067282191d4c1df2",
  "userName": "海致",
  "userType": "system",
  "exp": 过期时间戳
}
```

## 经验教训

- **Spring Boot JAR 打包**: Nested JAR 文件必须使用 STORED 模式（无压缩），否则启动时报 "compressed and nested jar files must be stored without compression"
- **JWT 字段兼容性**: iPaas 使用标准 JWT 字段（sub, name），需要兼容多种字段名
- **前端 Token 时序**: iframe 嵌入场景下，token 可能通过 postMessage 异步传递，需要等待后再调 API
