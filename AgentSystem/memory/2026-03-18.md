### Java 后端项目调试 - 401 问题解决

**问题**: 调用 iPaas `/user/getUserById` API 返回 401 "用户授权过期"

**根因分析**:
- 前端 JWT 解析成功 (UserId/UserName 有值)
- Token 未过期 (exp > current time)
- **真正问题**: `EventServiceImpl.java:905` 调用 iPaas API 时，错误地使用**前端传来的用户 JWT**作为 Authorization header
- iPaas API 需要的是**系统级 accessToken**（需要通过 OAuth 接口获取）

**修复方案**:
- 修改 `EventServiceImpl.java` 第 899-905 行
- 在调用 `/user/getUserById` 前，先调用 `getAccessToken(accessTokenUrl)` 获取系统 accessToken
- 使用 `accessToken.getAccess_token()` 替代 `userToken`

**代码修改**:
```java
// 修改前
httpGet.setHeader("Authorization", userToken);

// 修改后
AccessToken accessToken = getAccessToken(accessTokenUrl);
if (accessToken == null || StringUtils.isBlank(accessToken.getAccess_token())) {
    throw new SqxException("获取系统 accessToken 失败");
}
httpGet.setHeader("Authorization", accessToken.getAccess_token());
```
