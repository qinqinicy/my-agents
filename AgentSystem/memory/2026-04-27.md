# 2026-04-27 日志

## Oryx Web 管理界面部署

### 问题：Oryx 启动失败
- bootstrap 循环调用 start_redis → 无数 bootstrap 进程
- 原因：`exec /usr/local/oryx/platform/bootstrap` 在 start_redis 中导致递归调用
- 解决：start_redis 只负责加载环境变量，直接返回，让 bootstrap 继续执行

### 问题：端口 8080 绑定失败（errno=98）
- Oryx Go 服务监听 0.0.0.0:8080，Bind socket failed
- errno=98 = Address already in use，但 `ss -tlnp | grep 8080` 显示无占用
- 可能原因：容器网络模式或 SRS 残留进程

### 待处理
- [ ] Oryx 8080 端口问题：检查是否有其他进程占用或网络配置问题
- [ ] SRS 状态：确认是否还在运行（proxy_example、UA004768282 流）

### 经验教训
- Oryx start_redis 被 bootstrap 调用，不能用 `exec` 替换进程，否则递归
- 正确做法：start_redis 加载环境变量后直接返回，bootstrap 会继续执行 SRS 启动
- `source ~/.env` 在容器内可能失败，因为文件路径在 host 而非容器内
